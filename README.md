# DealFlow360

DealFlow360 is an enterprise B2B CPQ (Configure, Price, Quote) & Contract Lifecycle Management system.

## Project Structure

```text
dealflow360/
├── apps/
│   ├── server/           # Express.js REST API server
│   └── client/           # React + RTK Query frontend client
└── README.md
```

## Getting Started

### Backend (Server)
```bash
cd apps/server
npm install
npm run dev
```

### Frontend (Client)
```bash
cd apps/client
npm install
npm run dev
```
